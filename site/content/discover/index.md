## How a discovery works

Every discovery runs the same four steps, and each takes about a minute.

1. **Predict.** Choose an answer, then compare it with the explanation.
2. **Observe.** One link opens the simulation at the place that shows the answer, and a picture beside it works without 3D.
3. **Explain.** The idea in plain language, with the equation one click away.
4. **Change a parameter.** Use a calculator preset to Concordia's values to see how changing an input affects the result.

The questions introduce the effects of rotation, heat transfer and pressure containment. None needs more than school physics, and every number comes from the station's own fact sheet. Take them in any order.

The calculators run independently of the simulation, and each page links to the matching view so you can see the result there. For a guided story rather than questions, start with [the journey](/journey/), and for every place you can open, see the [scene atlas](/scenes/).
